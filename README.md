# たびのあと

## サイト概要

### サイトテーマ
ソロトラベラーが旅の記録を残し、同じ価値観のユーザーとゆるく繋がるためのソロ旅特化型SNS。

### テーマを選んだ理由
私自身、日常の喧騒から離れて静かな自然スポットへ一人で旅をすることや、ローカルフードを巡ることが趣味であり、日々の活力になっています。  
しかし、一般的なSNSでは、ソロトラベラーが求める「静かで居心地の良い穴場情報」が見つけにくいことや、既存のSNSでは他人の目が気になり、自分のための純粋な記録が難しいという課題を感じていました。  
そのため、他人の評価を気にせず自分だけの「旅の歩み（跡）」を気楽に残すことができ、さらに帰宅後も「旅の余韻（後）」を静かに楽しめるような、ソロトラベラーに寄り添ったSNSがあればいいなと考え、この「たびのあと」というテーマを選定いたしました。  

### ターゲットユーザ
* **静かな場所でリフレッシュしたい人**
  * 日々の忙しい仕事から離れ、週末に自然豊かな静かな場所へ1人で赴き、心身を整えたいと考えている人。
* **自分のペースで気ままに旅をしたい人**
  * 誰かと予定を合わせるのではなく、その日の気分でふらっとローカルグルメやニッチな観光地を巡るのが好きな人。
* **一般的なSNSの「繋がり」に疲れを感じている人**
  * 自分の旅の思い出を写真や日記として記録に残したいものの、他人の評価を気にしたくない人。

### 主な利用シーン
* **旅の最中・移動中（旅の【跡】を残すとき）**
  * 目的地に向かう電車の中や、立ち寄ったのんびりとしたカフェで、その瞬間に感じたことや目の前の風景を忘れないうちに「ひとり言」として写真付きで残したい時。
* **旅から帰ってきた自宅でのリラックスタイム（旅の【後】の余韻に浸るとき）**
  * 「今月はどこにお出かけできたかな」と、自分だけの足跡カレンダーや地図を眺めながら、旅の余韻に浸りつつ思い出を静かに振り返りたい時。
* **次の旅の行き先を計画・妄想している時**
  * 「次はどこに行こうか」と考えながら、自分と同じように静かでニッチなソロ旅を好む他のユーザーの投稿を眺めて、良さそうな場所を「行ってみたいリスト」にストックしたい時。
